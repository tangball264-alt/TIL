# 조인

두 개 이상의 테이블에서 데이터를 한 번에 조회할 수 있는 기능

FROM 절에서 수행.

예시 :

```
SELECT *
  FROM TAB1, TAB2 ;
```
TAB1
| COL1 | COL2 |
|------|------|
| 1 | 3 |
| 2 | 4 |

TAB2
| COL3 | COL4 |
|------|------|
| 5 | 7 |
| 6 | 8 |

결과 :
| COL1 | COL2 | COL3 | COL4 |
| --- | --- | --- | --- |
| 1 | 3 | 5 | 7 |
| 1 | 3 | 6 | 8 |
| 2 | 4 | 5 | 7 |
| 2 | 4 | 6 | 8 |

## 별칭 부여
병합되는 테이블들에 동일한 명칭의 컬럼이 존재할 수 있다(ex 학생 컬럼-id, 학과 컬럼-id)

이는 **테이블명.컬럼명** 방식으로 표기.

그러나, 테이블명이 길면 입력이 번거로우니 FROM절에서 별칭을 부여하고, SELECT, WHERE등에서 컬럼을 호출할 때 이 별칭을 이용한다(별칭.컬럼명)

관례적으로 A, B등 한 글자로 하며, 코드가 간결해짐.

```SQL
SELECT A.COL1, B.COL3
  FROM TAB1 A, TAB2 B;
```
위와 같이 테이블 이름 뒤에 한 칸 띄고 적기.

### 주의사항
한 번 from절에서 별칭을 부여하면 이후 where, select, group by, having, order by 등 sql의 나머지 절에서도 모두 그 명칭을 써야 함.


## 조인 개념
여러 테이블에 흩어져 있는 데이터를 한 번에 조회할 수 있도록 결합하는 기술

- 한 데이터를 가져오려면 여러 테이블이 필요할 때, 보다 적은 조회로 원하는 데이터를 가져올 수 있다.

- 데이터 품질 상승을 위해 정규화를 수행하며 테이블을 나누어 발생하는 조회의 불편을 조인으로 해소.

## 조인의 실행원리

### 카티션 곱
조인하는 (두) 테이블로부터 조합 가능한 모든 경우의 수를 산정.

최종 테이블의 크기 : 두 테이블 컬럼 수의 합 * 두 테이블 튜플 수의 곱

**from에 별도의 조치 없이 2개 이상 테이블을 입력하면, 기본적으로 카티션곱을 수행**

### 조인 조건
where 절에서 연관 조건을 지정하기.

카티션 곱의 문제(연관 없는 데이터가 붙어 과도한 데이터 발생)-> 조건 작성(연관성 있는 데이터만 남기기)

일반적으로 두 테이블 간 관계를 나타내는 기본 키와 외래키 이용.
```SQL
SELECT *
  FROM TAB1 A, TAB2 B
 WHERE A.PK = B.FK ;
```

### 일반 조건 추가
위의 **조인 조건**과 별개로, 원하는 일반 조건을 추가로 부여

## 조인의 순수 관계 연산자 표현
조인 : 나비모양 기호

```SQL
SELECT A.USERID, A.NAME, B.PHONENUMBER
  FROM USER A, USERNUMBER B
 WHERE A.USERID = B.USERID
   AND A.USERID = 'A0001'
   AND B.연락처구분 = '휴대폰';
```

## 동등 / 비동등 조인

### 동등 조인
**조인 조건에 동등 비교 연산자(=)만 사용하는 조인.**

기본적인 조인.

### 비동등 조인(Non-Equi Join)

조인 조건에 동등 비교 연산자(=)외의 **비교 연산자(>, <, BETWEEN, != 등)를 사용하는 조인**

특정 구간 또는 조건에 따라 연결할 때 사용됨. '범위 매칭'필요시 주로 사용

설계 구조나 데이터 타입에 따른 제약이 있을 수 있음.

예시
```SQL
SELECT *
  FROM 급여등급 A, 사원 B
 WHERE B.급여 BETWEEN A.최소급여 AND A.최대급여;
```

# 소인수분해

어떤 정수의 약수(인수)인 소수를 모두 구하는 것.

## 시행 나눗셈(Trial Division)

어떤 정수가 소수(Prime Number)인지 확인하거나, 그 수를 소인수분해할 때 사용하는 가장 원시적이면서도 확실한 수학적 방법

### 시행 나눗셈 원리

'나누어떨어지면, 더 이상 안 나눠질 때까지 계속 내누고 몫을 갱신한다.'

> 예시 : 숫자 20 기준
> 
> 가장 작은 소수 2로 나누기 : 20/2=10
>
> 몫이 10. 이걸 다시 2로 나누기 : 10/2=5
>
> 몫이 5. 이걸 다시 2로 나누기 : 나누어 떨어지지 않는다. 다음 숫자로 넘어간다.
>
> 3으로 시도 : 실패
>
> 4로 시도 : 실패
>
> 5로 시도 : 5/5=1
>
> 몫이 1. 소인수분해를 종료한다. 소인수는 2, 2, 5


## 재귀호출

내가 수행한 방법. 

add하기 편하게 list 이용하여 소인수분해.
이후 스트림으로 int[] 로 변환.


```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public int[] solution(int n) {
        int[] answer = getPrimeFactor(n).stream().mapToInt(Integer::intValue).toArray();
        return answer;
    }
    public List<Integer> getPrimeFactor(int n){
        List<Integer> list = new ArrayList<>();        
        if(list.size() == 0){
            list.add(n);
        }
        for(int i=2;i<=n/2;i++){
            if(n%i==0){
                list.addAll(getPrimeFactor(i));
                list.addAll(getPrimeFactor(n/i));
            }
        }

        Set<Integer> set = new TreeSet<>(list);
        List<Integer> answer = new ArrayList<>(set);
        return answer;
    }
}
```

# 배열 자르기

배열을 인덱스 a부터 인덱스 b까지만 남기고 자르는 문제

## 문제

정수 배열 numbers와 정수 num1, num2가 매개변수로 주어질 때, numbers의 num1번 째 인덱스부터 num2번째 인덱스까지 자른 정수 배열을 return 하도록 solution 함수를 완성해보세요.

## 내 풀이

```java
import java.util.*;
import java.util.stream.*;
class Solution {
    public int[] solution(int[] numbers, int num1, int num2) {

        int[] answer =  Arrays.stream(numbers).limit(num2+1).skip(num1).toArray();
        return answer;
    }
}
```
스트림의 skip과 limit을 사용

## 다른 풀이1 : 가장 간결하게

```java
import java.util.*;

class Solution {
    public int[] solution(int[] numbers, int num1, int num2) {
        return Arrays.copyOfRange(numbers, num1, num2 + 1);
    }
}
```

arrays 메서드인 copyOfRange로 배열의 지정 범위만 복사하여 정답으로 삼음.

배열 복사 전용 저수준 메서드로 메모리 블록을 통채로 복사한다.

## 다른 풀이 2  : stream을 이용하여
```java
import java.util.stream.IntStream;

class Solution {
    public int[] solution(int[] numbers, int num1, int num2) {
        return IntStream.rangeClosed(num1, num2).map(i -> numbers[i]).toArray();
    }
}
```
rangeClosed로 필요한 크기에 맞는 스트림을 생성. 그 후 map으로 원본 numbers에 접근하여 값을 가져옴.

## 비교

속도
1. 풀이 1(copyOfRange)
2. 풀이 2(IntStream.rangeClosed + map)
3. 내 풀이(Arrays.stream + limit,skip)

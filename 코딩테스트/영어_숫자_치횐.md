# 영어 숫자 치환

## 문제

> 문제 설명
>
> 영어가 싫은 머쓱이는 영어로 표기되어있는 숫자를 수로 바꾸려고 합니다. 문자열 numbers가 매개변수로 주어질 때, numbers를 정수로 바꿔 return 하도록 solution 함수를 완성해 주세요.

> 제한사항
>
> - numbers는 소문자로만 구성되어 있습니다.
>
> - numbers는 "zero", "one", "two", "three", "four", "five", "six", "seven", "eight", "nine" 들이 공백 없이 조합되어 있습니다.
>
> - 1 ≤ numbers의 길이 ≤ 50
>
> - "zero"는 numbers의 맨 앞에 올 수 없습니다.

## 내 풀이

```java
import java.util.*;
class Solution {
    public long solution(String numbers) {
        Map<String, Integer> map = Map.of("zero", 0, "one", 1, "two", 2, "three", 3, "four", 4, "five", 5, "six", 6, "seven", 7, "eight", 8, "nine", 9 );
        long answer = 0;
        for(Map.Entry<String, Integer> entry : map.entrySet()){
            numbers = numbers.replaceAll(entry.getKey(), String.valueOf(entry.getValue()));
        }
        answer = Long.parseLong(numbers);
        return answer;
    }
}
```

1. 영어-숫자 맵을 생성
- Map.of()로 0~9 영어-숫자 데이터를 한 번에 넣어 고정 맵 생성.
2. for 문으로 맵의 entry를 받아 순회
- for(Map.Entry<String, Integer> entry : map.entrySet()) 방식으로 엔트리 순회
3. 각 순회에서 .replaceAll로 치환.
- 이 때, 나는 초기 맵 생성에서 string integer 형식으로 했으나, 이를 "1"같은 string으로 저장했다면 String.valueOf로 변환하는 번거로움이 없었을 것.
4. 취득한 숫자(String)을 long으로 변환
- Integer.parseInt대신 Long.parseLong사용

## 더 나은 풀이

### array 사용
간단하게는 map이 아니라, array로도 해결할 수 있다. array의 인덱스가 0-9가 되므로 맵까지는 불필요. String[] 생성으로 처리 가능.

### 완전 탐색 기반 문자열 매칭

슬라이딩 윈도우와 직접 비교 방식을 통해 탐색한다.

순회가 단방향으로 1회만 이루어지고, 단어 길이가 제한적이기에 연산량이 적다.

startWith() : 문자열이 특정 문자로 시작하는지 확인해 참/거짓 반환.

python은 문자열.startswith()형태. 튜플 이용해 여러 개 중 하나로 시작하는지 한 번에 검사.

java는 문자열.startsWith() 형태. 시작 위치(인덱스)를 두 번째 파라미터로 입력 가능.

C#은 문자열.StartsWith()제공.

1. while로 문자열 전체를 순회
2. 그 안에서 각 회마다 for로 zero-nine까지 반복하여 startsWith(if문 조건절)
3. 매칭된다면(if) sb에 글자 추가 후 매칭된 단어의 길이만큼 +
4. 만약 for문 끝까지 매칭이 안되면 +1(이론상 가능성 없음)
5. sb를 long으로 전환.

#### 주요 메서드

- 문자열.startsWith(단어, 인덱스)
- Long.parseLong()
- sb.toString()

그외 일부 부분은 위의 array로 전환하면 좋을 듯 하여 생략.

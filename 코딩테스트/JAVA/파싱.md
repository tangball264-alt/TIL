# 파싱(Parsing)

덩어리로 된 원본 데이터를 컴퓨터가 이해하고 가공하기 쉬운 형태로 쪼개고 분석하는 과정

## 종류

개발에서 쓰이는 파싱들

1. 데이터 포멧 파싱

JSON, XML 등의 거대한 문자열 덩어리 데이터를 자바 객체 형태로 쪼개기.

"{ "name": "김철수", "age": 25 }" 같은 데이터를 user객체로 만들어 user.getName()메서드 등으로 호출 가능하게 됨.

작게는 글자 덩어리 "10"을
Integer.parseInt("10")을 이용해 숫자 10으로 바꾸는 것도 파싱.


2. 웹 크롤링 / HTML 파싱

웹페이지 전체의 HTML소스코드를 긁어와 거기서 필요 정보(ex, 뉴스 제목, 상품 가격)만 골라내는 작업. 파서(parser) 프로그램 이용.

3. 컴파일러의 소스코드 파싱

컴파일러가 코드의 요소들을 잘게 쪼개어 문법 오류가 없는지 분석.

# 비교

## 일반 비교

비교 연산자 >, <, >=, <=, ==, != 사용.

## 문자열 비교

**문자열을 ==로 비교하면 안됨**

문자열에서

1. **동일성 비교(Identity)** : == 기호로 두 객체가 지시하는 **주소값 비교**. 참조 비교라고도 부름.
2. **동등성 비교(Equality)** : .equals() 메서드로 두 객체가 가진 **데이터(값) 비교**. 

단, 이는 if문처럼 조건식을 작성하는 경우에만 해당.

switch-case문에서 비교할 경우 equals처럼 내용을 비교.

```java
String k = "up";
switch(k){
    case "up": ...    // k.equals("up")과 동일한 효과
}
```

예외적으로, matches()함수와 정규식을 이용해 복잡한 문자열 비교를 하거나, contains()함수로 특정 글자의 포함 여부를 체크할 수 있다.

## 정밀한 숫자
BigDecimal

.compareTo() 메서드 사용.

A.compareTo(B) 형식으로 사용하며, A == B면 0, A > B면 양수, A < B면 음수 반환.

이쪽도 일반 비교연산자 쓰면 주소값 비교 되는 등 오류.

## 객체

Comparable / Comparator 등 overriding해서 개발자가 직접 비교 기준 작성.

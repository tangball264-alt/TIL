# 데이터 타입 변환

## 기본 타입 간 변환

기본 타입(Primitive) 종류

1. 정수 : int, long
2. 실수 : float, double
3. 문자 : char

기본 타입 간 변환은 공식적으로 **캐스팅(Casting)**또는 **형변환**이라 한다.

자동 형변환(Upcasting / Promotion) : 작은 타입에서 큰 타입으로 갈 때, 자동으로 형변환됨(int->double)

강제 형변환(Downcasting / Demotion) : 큰 타입에서 작은 타입으로 갈 때. 데이터 손실 위험이 있어 괄호()를 이용해 명시.((int) doubleValue)

### 큰 타입과 작은 타입

자바 '기본 타입의 크고 작음' = 변수가 차지하는 메모리 방의 크기와 표현할 수 있는 숫자의 범위를 말함.

크기 순서(작은것 -> 큰 것)
1. byte(1Byte)
2. short(2Byte)
3. char(2Byte)
4. int(4Byte) 약 -21억 ~ 21억
5. long(8Byte)
6. float(4Byte) 소수점 아래 6~7자리까지만 정확히 표현
7. double(8Byte)

int -> double변환은 가능하도 double->int로 가면 소숫점 아래가 잘리는 등 손실 발생.


## String 객체 <-> 기본 타입

객체(클래스)인 String을 기본 타입으로 변환하는 것.

참조 타입(Object)인 String과 기본타입인 int등은 숫자 캐스팅 불가.

정식 명칭 : 타입 변환(Type Conversion) 또는 [데이터 파싱(Parsing)](파싱.md#종류)

### 문자열 <-> 숫자

문자열 -> 숫자 : 파싱. 
- Integer.parseInt(), Double.parseDouble() 등 메서드 이용.

숫자 -> 문자열 : 문자열 변환
- String.valueOf() 메서드 이용

### 문자 <-> 문자열

char -> String : String.valueOf()사용. 혹은 char+""(빈 문자열 더하기)

String -> char : .charAt() 사용. 인덱스 번째 글자 꺼내기.

#### 문자열 -> 문자 배열

문자열 전체를 이루는 모든 글자를 쪼개어 char배열로 만들기.

.toCharArray() 사용.




## 자료구조 간 변환

List <-> Array, Stream -> 자료구조 등 변환.

한 자료구조의 데이터를 다른 자료구조의 방에 옮겨 담는 것.

정식 명칭 : 자료구조 변환(Collection Conversion) 또는 스트림 수집(Stream Collection)

리스트 -> 배열 : 배열 변환
- toArray()

배열 -> 리스트 : 리스트 생성/변환
- Arrays.asList() 또는 List.of()

스트림 -> 자료구조 : 수집(Collecting)
- .collect(Collectors.toList())나 .toArray()등 메서드 이용

```java
// 스트림 컬렉팅(수집) 예시: 스트림을 정렬한 뒤 다시 리스트로 변환
List<String> sortedList = list.stream().sorted().collect(Collectors.toList());
```

# 정규식

## 개념
Regular Expression. 통칭 regex.

문자열에서 특정 패턴을 찾기 위한 패턴 표현 언어.

거의 모든 프로그래밍 언어가 지원하며, 작동 원리는 대개 비슷함.(다만 정규식을 사용하는 문법, 내장 함수 등은 다름.)

또한 코드 에디터, SQL DB, 리눅스/유닉스 터미널 명령어 등에서도 정규식 사용.

## 필요성

복잡한 문자열 검증, 추출, 치환 로직을 짧은 패턴 하나로 가능하게 한다.

**사용처**

- 이메일 형식인지 확인
- 전화번호 형식인지 확인
- 숫자만 뽑아내기
- 특정 문자 제거

## 자바에서 정규식을 사용하는 메서드

1. matches(regex) : 문자열 전체가 패턴과 정확히 일치하는지 확인(boolean 반환)
2. replaceAll(regex, 대체값) : 패턴에 맞는 모든 부분을 치환(string 반환)
3. replaceFirst(regex, 대체값) : 패턴에 맞는 첫 번째 부분만 치환
4. split(regex) : 패턴 기준으로 문자열을 쪼갬.

## 라이브러리
더 정교한 제어 위해서는 패키지를 import해 Pattern, Matcher클래스를 사용.
```java
import java.util.regex.*;
Pattern p = Pattern.compile("[aeiou]");   // 패턴을 미리 컴파일
Matcher m = p.matcher(my_string);         // 이 패턴으로 문자열을 검사할 도구 생성
boolean found = m.find();                  // 매치되는 부분이 있는지 확인
```

## 핵심 문법

### 문자 집합 []

> [aeiou] : a, e, i, o, u중 하나
>
> [a-z] : 소문자 알파벳 중 하나
>
> [0-9] : 숫자 중 하나
>
> [^aeiou] : a, e, i, o, u가 아닌 문자(대괄호 맨 앞 ^로 부정 표시)

### 미리 정의된 축약 표현

> \d : 숫자 하나([0-9]와 동일)
>
> \D : 숫자가 아닌 문자
>
> \s : 공백류 문자(스페이스, 탭, 줄바꿈 등)
>
> \S : 공백이 아닌 문자
>
> \w : 단어 문자(알파벳, 숫자, 언더스코어)
>
> \W : 단어 문자가 아닌 것
>
> . : 줄바꿈 제외 아무 문자 하나

### 개수(반복)지정 - 수량자(Quantifier)

> * : 0개 이상
>
> + : 1개 이상
>
> ? : 0개 또는 1개
>
> {n} : n개
>
> {n, } : n개 이상
>
> {n, m} : n개 이상 m개 이하

```java
"a*"     // "", "a", "aa", "aaa"... 전부 매치
"a+"     // "a", "aa", "aaa"... (최소 1개)
"\\d{3}" // 숫자 정확히 3자리
```

### 위치 지정(Anchor)

> ^ : 문자열의 시작
>
> $ : 문자열의 끝

```java
"^a"   // "a"로 시작
"z$"   // "z"로 끝
```

*문자집합의 대괄호 안에 들어가는 ^와는 별개. 대괄호 안의 것이  부정, 대괄호 밖의 것이 문자열 시작.*

### 그룹화와 OR

> () : 그룹핑. 
>
> | : OR

```java
"(ab)+"      // "ab", "abab", "ababab"... (괄호로 묶은 단위를 반복)
"cat|dog"    // "cat" 또는 "dog"
```

### 이스케이프가 필요한 특수문자

정규식에서 ., *, +, (, ), [, ] 등은 특수한 의미를 가짐.
-> 이 문자들을 "실제 표기될 그대로의 문자"로 매치하려면 \(역슬래시)를 이용해 이스케이프 할 것.

```java
"3\\.14"   // "3.14"라는 문자 그대로 (이스케이프 안 하면 .은 "아무 문자"를 의미)
```

**이때, 정규식에서 이스케이프를 위해 \. 등을 작성하고, 그걸 자바 문자열 자체의 이스케이프로 해석하는 걸 막기 위해 한 번 더 이스케이프해야 함. 따라서 \\. 처럼 2회의 역슬래시 사용**

*즉, 자바 문자열""안에서 정규식 작성 시 백슬래시를 하나 더 쓰고, TextBlock이나 정규식 전용 문법에서는 기본대로 하나만 쓴다.*

*단, 문자 집합의 대괄호 안에서는 대부분 문자 그대로로 취급되기에 백슬래시 없이 그냥 써도 된다.*

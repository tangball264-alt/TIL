# 컬렉션(Collection)

## 컬렉션 정의

java.util 패키지에 있는 **자료구조들을 다루는 프레임워크**

가변크기, 다양한 형식

## 종류
|인터페이스 | 대표 구현체 | 특징 |
|---|---|---|
| List | ArrayList, LinkedList | 순서, 중복 있음. |
| Set | HashSet, TreeSet | 순서x, 중복x |
| Map | HashMap, TreeMap | key-value쌍 저장 |

## 선언

```java
List<Integer> list = new ArrayList<>();
list.add(1);
list.add(2);

Set<String> set = new HashSet<>();
set.add("apple");
```

## 상세

### Set

중복을 허용하지 않는 컬렉션.

#### Set 대표 구현체
1. HashSet
- 순서 보장 안됨(내부 해시 테이블로 저장)
- 조회, 추가, 삭제 빠름(평균 O(1))
2. LinkedHashSet
- 순서 기억함.
- 성능은 HashSet과 비슷
3. TreeSet
- 정렬된 순서 유지
- HashSet보다 느림

단, 특정 값을 지정(인덱스)해 꺼내는 방법이 없다.

대신 특정 값이 존재하는가를 확인하거나(set.contains(5)), for문에서 
```java
for(Integer value : set){
    System.out.println(value);
}
```
이와 같이 전체 값을 순회할 수 있고,
```java
List<Integer> list = new ArrayList<>(set);
int value = list.get(0);  // 이제서야 인덱스 접근 가능
```
이와 같이 list로 감싸 변환하여 사용할 수 있음.

#### Set 주요 메서드

.add(E e) : 데이터 추가. 이미 같은 데이터가 있다면 축 없이 false반환.
.remove(Object o) : 특정 데이터 찾아 삭제. 삭제 성공하면 true 반환.
.contains(Object o) : 특정 데이터가 Set안에 들어가 있는가 확인. 속도 매우 빠름.
.size() : 현재 set안의 데이터 개수(길이)반환
.clear() : 현재 set안의 모든 데이터 지우고 비움
.isEmpty() : set이 비었으면 true, 데이터 하나라도 있으면 false반환.

### Map

<키, 값> 쌍으로 데이터를 저장하는 자료구조.

대원칙 : Key는 중복될 수 없다.

+ 맵 내부적으로 Entry객체가 존재. 키-값 쌍 하나하나를 별도의 엔트리 객체로 표현하며, Map.Entry<Type, Type> 타입으로 표기 가능.

#### Map 대표 구현체

1. HashMap
- 순서 없음. 정렬도 없음.
- 검색, 추가, 삭제 초고속(O(1))
2. LinkedHashMap
- 데이터가 들어온 순서 기억함.
- HashMap보다 아주 조금 더 메모리 소모량이 크고 속도가 느릴 수 있다.
- n번째 값을 꺼낼 수 있는 건 아니고, 넣은 순서대로 루프돌며 출력/가공하기 적합
3. TreeMap
- Key를 기준으로 자동 정렬한다. 데이터 입력시마다 작동
- 이진 검색 트리 기반.
- 데이터 추가/삭제 속도는 O(logN) 으로 보통.
- 특수 메서드(가장 큰/작은 값 추출 메서드) 제공

#### Map 주요 메서드

1. 공용 메서드

put(K key, V value): 키-값 쌍 추가. 이미 존재하는 키라면 값을 덮어쓴다.

putIfAbsent(K key, V value): 기존 데이터가 없다면 키-값 쌍을 넣는다. 있다면 생략한다.

putAll(Map m): 다른 Map의 모든 데이터를 현재 Map에 통째로 복사해 넣는다.


get(Object key): 지정 key의 값을 반환.

getOrDefault(Object key, V defaultValue): get을 실행하되, 대상 키가 Map에 없다면 지정한 값을 반환한다.

containsKey(Object key): 특정 키가 Map에 존재하는지 확인. True/False반환.

containsValue(Object value): 특정 값이 Map에 존재하는지 확인. True/False 반환

remove(Object key): 지정한 키와 그 쌍인 값을 Map에서 삭제 + 삭제한 값(Value) 반환

size(): 현재 Map의 키-값 쌍 개수 반환.

isEmpty(): Map이 텅 비어있으면 true, 하나라도 있으면 false 반환.

clear(): Map 안의 모든 데이터 소거.

keySet(): Map의 모든 키만 모아서 Set 자료형으로 반환.(루프 돌릴 때 필수)

values(): Map의 모든 값만 모아서 Collection 형태로 반환합니다.

entrySet(): Key와 Value를 묶은 Map.Entry 객체들을 Set으로 반환하여, 키와 값을 동시에 순회할 수 있게 해줍니다.

- Set<Map.Entry<K, V>> entrySet() 같은 형태가 될 것.

2. TreeMap 전용 메서드

firstKey() / lastKey(): 가장 작은 / 큰 키 가져오기.

firstEntry() / lastEntry(): 가장 작은 / 가장 큰 키-값 쌍(Entry) 가져오기

pollFirstEntry() / pollLastEntry(): 가장 작은 / 가장 큰 쌍 반환 + 영구 삭제.(우선순위 큐 기능)

lowerKey(K key) / higherKey(K): 지정 키보다 작은 키 중 가장 큰 것 / 큰 키 중 가장 작은 것 반환.(이상/이하 아니고 초과/미만)

floorKey(K key) / ceilingKey(K): 지정 키 포함 이하인 키 중 최대치 / 이상인 키 중 최소치. 지정 키가 있다면 그걸 반환할 것이고, 없다면 그것보다 작지만 / 크지만 가장 가까운 값을 반환.

subMap(fromKey, toKey): fromKey부터 toKey 전까지의 구간만 잘라 새 Map으로 반환.

headMap(toKey) / tailMap(fromKey): 처음부터 toKey까지 앞부분만 자르기 / fromKey부터 끝까지 뒷부분만 자르기.

descendingMap(): 전체 맵의 정렬 순서를 완전히 뒤집은 역순(내림차순) 맵을 새로 만들어 반환.

3. LinkedHashMap 전용 특수 메서드

LRU 캐시 구현용으로 오래된 데이터를 자동 지우는 게 가능

removeEldestEntry(Map.Entry eldest) 오버라이딩해 한계치 + 들어온 것 기준/사용 기준으로 오래된 것 지정.

딱히 오버라이딩 안하면 반드시 false를 반환하는 기본 구조에 따라 별도의 작동을 하지 않음.

# 컬렉션(Collection)

## 컬렉션

java.util 패키지에 있는 **자료구조들을 다루는 프레임워크**

가변크기, 다양한 형식

### 종류
|인터페이스 | 대표 구현체 | 특징 |
|---|---|---|
| List | ArrayList, LinkedList | 순서, 중복 있음. |
| Set | HashSet, TreeSet | 순서x, 중복x |
| Map | HashMap, TreeMap | key-value쌍 저장 |

### 선언

```java
List<Integer> list = new ArrayList<>();
list.add(1);
list.add(2);

Set<String> set = new HashSet<>();
set.add("apple");
```

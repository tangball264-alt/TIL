# 겹치는 선분의 길이

## 문제

문제 설명
선분 3개가 평행하게 놓여 있습니다. 세 선분의 시작과 끝 좌표가 [[start, end], [start, end], [start, end]] 형태로 들어있는 2차원 배열 lines가 매개변수로 주어질 때, 두 개 이상의 선분이 겹치는 부분의 길이를 return 하도록 solution 함수를 완성해보세요.

lines가 [[0, 2], [-3, -1], [-2, 1]]일 때 선분이 두 개 이상 겹친 곳은 [-2, -1], [0, 1]로 길이 2만큼 겹쳐있습니다.

>제한사항
>
>lines의 길이 = 3
>
>lines의 원소의 길이 = 2
>
>모든 선분은 길이가 1 이상입니다.
>
>lines의 원소는 [a, b] 형태이며, a, b는 각각 선분의 양 끝점 입니다.
>
> * -100 ≤ a < b ≤ 100

### 유의사항

1. 세 선분 중 어느게 가장 앞인지는 불명
2. 세 선분이 중복으로 겹치는 구간이 있을 가능성을 고려해야 함.

## 내 답안

```java
import java.util.*;
class Solution {
    public int solution(int[][] lines) {
        int min = Math.min(Math.min(lines[0][0], lines[1][0]), lines[2][0]);
        int max = Math.max(Math.max(lines[0][1], lines[1][1]), lines[2][1]);
        int[] lineArr = new int[max-min+1];
        for(int i=0;i<3;i++){
            for(int j = lines[i][0];j < lines[i][1];j++){
                lineArr[j-min]++;
            }
        }
        int answer = 0;
        for(int i=0;i<lineArr.length;i++){
            if(lineArr[i]>=2){
                answer++;
            }
        }
        return answer;
    }
    
}
```
### 특징

1. 선들의 범위 만큼의 길이를 가진 배열 lineArr을 가지고, 각 범위에 지나가는 선을 센다.
2. min, max를 가지고 선의 값을 배열의 index로 치환.(오프셋 계산)

## 다른 답안

1. HashMap + merge + Stream

```java
Map<Integer, Integer> map = new HashMap<>();
for (int[] line : lines) {
    int from = Math.min(line[0], line[1]);
    int to = Math.max(line[0], line[1]);
    for (int i = from; i < to; i++) {
        map.merge(i, 1, Integer::sum);
    }
}
return (int) map.values().stream().filter(i -> i > 1).count();
```

- 해시맵을 이용해 좌표별 카운트 계산. 나와 달리 index와 좌표 전환 불필요.
- merge(key, 1, Integer::sum) 는 Map.merge() 메서드. 키가 없으면 값을 새로 추가하고, 이미 키가 있으면 **기존 값과 새 값을 합친다**. map.merge(key, value, 병합함수); 형식. putIfAbsent(K key, V value)와 비슷하지만 다르다.
- 각 선분에서 {시작값, 종료값} 순서는 고정이라 from과 to를 구할 필요는 없음.
- 2이상의 값의 개수를 세는 건 stream 이용.


2. 좌표 범위를 직접 순회
```java
for (int i = -100; i < 100; i++) {
    int line = 0;
    if (lines[0][0]<=i && lines[0][1]>i) line++;
    if (lines[1][0]<=i && lines[1][1]>i) line++;
    if (lines[2][0]<=i && lines[2][1]>i) line++;
    if(line > 1) answer++;
}
```
- for문으로 좌표 범위(제한사항 : -100~100)를 1회 순회.
- 1번 선 / 2번 선 / 3번 선 각각 if문으로 해당 값을 지나는지 확인
- 메모리 효율적(배열/맵 생성 x).

3. HashMap + getOrdefault
- 기본 원리가 1안과 유사하여 생략
- 다만 merge대신 map.put(j, map.getOrDefault(j, 0) + 1);
- 최종 집계도 for문.

# 특이한 정렬


## 문제

>문제 설명
>
>
>정수 n을 기준으로 n과 가까운 수부터 정렬하려고 합니다. 이때 n으로부터의 거리가 같다면 더 큰 수를 앞에 오도록 배치합니다. 정수가 담긴 배열 numlist와 정수 n이 주어질 때 numlist의 원소를 n으로부터 가까운 순서대로 정렬한 배열을 return하도록 solution 함수를 완성해주세요.

>제한사항
>
>- 1 ≤ n ≤ 10,000
>
>- 1 ≤ numlist의 원소 ≤ 10,000
>
>- 1 ≤ numlist의 길이 ≤ 100
>
>- numlist는 중복된 원소를 갖지 않습니다.

## 내 방법 1

혼자 
```java
import java.util.*;
class Solution {
    public int[] solution(int[] numlist, int n) {
        Arrays.sort(numlist);
        int m = (Arrays.binarySearch(numlist, n)>=0)?Arrays.binarySearch(numlist, n):-(Arrays.binarySearch(numlist, n)+1);
        int[] p1 = {m, numlist[m]-n};
        int[] p2 = {m-1, n - numlist[m-1]};
        int[] answer = new int[numlist.length];
        for(int i=0;i<answer.length;i++){
            if(p1[1]<=p2[1]){
                answer[i]=numlist[p1[0]];
                p1[0]++;
                if(p1[0]<answer.length){
                    p1[1]=numlist[p1[0]]-n;
                }
                else{
                    p1[1] = 10000;
                }
            }
            else if(p2[1]<p1[1]){
                answer[i]=numlist[p2[0]];
                p2[0]--;
                if(p2[0]>=0){
                    p2[1]=n-numlist[p2[0]];
                }
                else{
                    p2[1] = 10000;
                }
                
            }
        }
        
        return answer;
    }
}
```

다만, 코드 자체가 너무 길고 복잡해지는 점에서 그리 좋아 보이지 않는다.

### AI 제안 방법

numlist(int[]) → boxedNumbers(Integer[]) 변환 → Comparator로 (거리 오름차순, 값 내림차순) 정렬 → answer(int[])로 변환 후 반환

```java
import java.util.*;

class Solution {
    public int[] solution(int[] numlist, int n) {
        Integer[] boxedNumbers = Arrays.stream(numlist).boxed().toArray(Integer[]::new);

        Arrays.sort(boxedNumbers, Comparator
            .<Integer>comparingInt(num -> Math.abs(n - num))
            .thenComparing(Comparator.<Integer>naturalOrder().reversed()));

        return Arrays.stream(boxedNumbers).mapToInt(Integer::intValue).toArray();
    }
}
```
- Stream을 이용해 int[]를 Integer[]로 변환
- 배열의 정렬 기능 이용. 단, Comparator으로 정렬 조건 설정.
- 정렬 조건 : 각 값(num)과 n의 차이(절댓값)을 가지고 비교. 또한 그 값이 같을 경우 원래 값을 기준으로 내림차순으로.


int[]는 정렬 기준 커스텀이 불가능(무조건 오름차순). 

정렬 기준 지정은 Arrays.sort(T[] a, Comparator<? super T> c) 형태 필수.

-> 자바 제네릭 문법상 Comparator<Integer> 처럼 참조 타입만을 파라미터로 받을 수 있으므로 대상인 배열을 Integer로 변환해야.



### 다른 사람 풀이

1. 스트림

```java
import java.util.Arrays;

class Solution {
    public int[] solution(int[] numList, int n) {
        return Arrays.stream(numList)
                .boxed()
                .sorted((a, b) -> Math.abs(a - n) == Math.abs(b - n) ? b.compareTo(a) : Integer.compare(Math.abs(a - n), Math.abs(b - n)))
                .mapToInt(Integer::intValue)
                .toArray();
    }
}
```

import java.util.*;
class Solution {
    public int[] solution(int[] numlist, int n) {

        int size = numlist.length;
        for(int i=0; i<size-1; i++){
            for(int k=i+1; k<size; k++){
                int a = (numlist[i] - n) * (numlist[i] > n ? 1 : -1);
                int b = (numlist[k] - n) * (numlist[k] > n ? 1 : -1);
                if(a > b || (a == b && numlist[i] < numlist[k])){
                    int temp = numlist[i];
                    numlist[i] = numlist[k];
                    numlist[k] = temp;
                }

            }
        }
        return numlist;
    }
}

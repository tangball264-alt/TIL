# 저주의 숫자 3

## 문제

문제 설명
3x 마을 사람들은 3을 저주의 숫자라고 생각하기 때문에 3의 배수와 숫자 3을 사용하지 않습니다. 3x 마을 사람들의 숫자는 다음과 같습니다.

| 10진법 | 3x 마을에서 쓰는 숫자 | 10진법 | 3x | 마을에서 쓰는 숫자 |
|---|---|---|---|---|
| 1 | 1 | 6 | 8 |
| 2 | 2 | 7 | 10 |
| 3 | 4 | 8 | 11 |
| 4 | 5 | 9 | 14 |
| 5 | 7 | 10 | 16 |
정수 n이 매개변수로 주어질 때, n을 3x 마을에서 사용하는 숫자로 바꿔 return하도록 solution 함수를 완성해주세요.

제한사항
1 ≤ n ≤ 100


## 내 풀이

```java
class Solution {
    public int solution(int n) {
        int tenx = 1;
        int threex = 1;
        while(tenx <= n){
            if((threex)%3==0){
                threex+=1;
            }
            else if(String.valueOf(threex).contains("3")){
                threex+=1;
            }
            else{
                threex++;
                tenx++;
            }
        }
        return threex-1;
    }
}
```

while 반복문으로 진행.

숫자 1부터 n까지 에스컬레이트하며 진행.

단, if-else문을 통해 세 갈래로 나뉜다
- 현재 값이 3의 배수
- 현재 값에 3이 포함
- 위의 가능성에 포함되지 않으므로 정상적으로 다음 값으로 넘어간다.

### 평가

3이 포함되었는지 검증하기 위해 valueOf와 contain을 사용하는 것은 비효율적. 차라리 %10과 /10을 활용하여 각 자릿수를 검증하는 것이 옳다.


### 수정안

```java
boolean hasThree = false;
int temp = threex;
while(temp > 0){
    if(temp % 10 == 3){ hasThree = true; break; }
    temp /= 10;
}
```

대략 이렇게 삽입하여 수정할 것.

## 다른 풀이
```java
class Solution {
    public int solution(int n) {
        int answer = 0;

        for (int i = 1; i <= n; i++) {
            answer++;
            if (answer % 3 == 0 || String.valueOf(answer).contains("3")) {
                i--;
            }
        }

        return answer;
    }
}
```

원리는 동일하되, 나처럼 if-else if로 분할하지 않고 or문으로 조건문을 작성함 + while문 대신 for문 + tenx 대신 i를, --로 사실상 증가를 멈춘다.

장점 : 최종값에 -1 할 필요가 없음.

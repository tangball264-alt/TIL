# 배열 뒤집기

## 문제

문제 설명
정수가 들어 있는 배열 num_list가 매개변수로 주어집니다. num_list의 원소의 순서를 거꾸로 뒤집은 배열을 return하도록 solution 함수를 완성해주세요.

## 방안

1. for문을 이용해 num_list에서 역순으로 가져오기
2. stream API(IntStream) 이용하기
3. java.util.Collections 라이브러리의 reverse 메서드를 활용.

---

### 1번안 상세 설명

```java
class Solution {
    public int[] solution(int[] num_list) {
        int[] answer = new int[num_list.length];
        for(int i=0;i<num_list.length;i++){
            answer[i]=num_list[num_list.length-1-i];
        }
        
        return answer;
    }
}
```

- for문으로 반복한다.
- num_list의 값들을 역순으로 가져온다.
- answer에 정순으로 넣는다.


-> 실제 속도 빠름.

-> 코드는 조금 길어짐.

### 2번안 상세 설명

```java
import java.util.stream.*;
class Solution {
    public int[] solution(int[] num_list) {
        int[] answer = IntStream.rangeClosed(1, num_list.length)
        .map(i -> num_list[num_list.length - i])
        .toArray();
        
        return answer;
    }
}
```
num_list를 [2, 4, 6, 8, 10]으로 가정하면 풀이 해설
> answer배열의 내용을 다음의 스트림의 결과로 한다. : 
> IntStream을 생성, 이 때 기본 값으로 1, 2, 3, 4, 5(1~5)를 갖는다.
> 그리고 값이 1인 것에 4번 인덱스 값(10)을, 2인 것에는 3번 인덱스 값(8)을.... 해서 각각 매핑.
> 결과를 원하는 형태(배열)로 얻기 위해 결과 함수는 toArray()
> 반환.

### 3번안 상세 설명


```java
import java.util.Collections;
import java.util.*;
import java.util.stream.*;
class Solution {
    public int[] solution(int[] num_list) {
        List<Integer> list = Arrays.stream(num_list)
            // 리스트 생성. 값은 Arrays.stream으로 num_list 그대로 가져와서
            .boxed()
            //원시타입 IntStream으로 들어온 걸 객체타입(Stream<Integer>)로 바꿔서
            .collect(Collectors.toList());
            //결과물을 리스트로 변환하여 반환한 값을 사용.
        Collections.reverse(list); //그리고 얻은 list를 collections의 reverse메서드로 뒤집기.
        int[] reversed = list.stream() 
            //그리고 얻은 뒤집힌 리스트 내용의 배열 위해 일단 리스트 내용 스트림으로 가져다가
            .mapToInt(Integer::intValue) 
            //이전에 boxed로 Stream<Integer>로 바꾼 거 IntStream으로 돌리고
            .toArray(); //결과를 배열로 반환.
        
        return reversed;
    }
}
```

- num_list내용의 리스트 생성 -> 스트림으로 내용 받고 타입 변환해서 내용 채움.
- 리스트를 Collections.reverse로 순서 뒤집기
- 결과로 반환할 형식이 배열이므로, 다시 스트림으로 리스트의 내용을 받아 배열에 넣기.

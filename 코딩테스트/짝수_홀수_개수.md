# 짝수 홀수 개수

배열의 내용물을 조건에 따라 분리하여 각 조건별 해당 값을 세는 문제.

## 문제
정수가 담긴 리스트 num_list가 주어질 때, num_list의 원소 중 짝수와 홀수의 개수를 담은 배열을 return 하도록 solution 함수를 완성해보세요.

## 내 풀이

```java
class Solution {
    public int[] solution(int[] num_list) {
        int even_cnt = 0;
        for(int i=0;i<num_list.length;i++){
            if(num_list[i]%2==0){
                even_cnt++;
            }
        }
        int[] answer = {even_cnt, num_list.length-even_cnt};

        return answer;
    }
}
```

기본적으로 for문에 if문을 더해서 세는 방법.

## 다른 풀이

### 1번 대안
*AI 제안*

대안 1: Stream + filter + count
- 짝수 조건으로 걸러낸 후 개수만 세는 방식
- 핵심 메서드: IntStream으로 변환 후 filter(조건), 그리고 개수를 반환하는 최종 연산 메서드 (이전에 다뤘던 표에 있음)
- 홀수는 짝수 개수를 전체 길이에서 빼는 방식으로 구하거나, 조건을 반대로 한 번 더 filter+개수세기를 적용하는 방식 둘 다 가능


```java
    public int[] solution(int[] num_list) {
        int evenCount = (int) Arrays.stream(num_list)
                .filter(n -> n % 2 == 0)
                .count();
        return new int[]{evenCount, num_list.length - evenCount};
    }
```

count 함수는 long 형식으로 반환하기 때문에 (int)를 이용해 변경함.

num_list배열 내용을 스트림으로 받아 -> filter로 짝수만 남기고 -> 그 개수를 세어 나온 long값을 -> int로 형변환하여 evenCount에 넣는다.

### 2번 대안

*다른 사람 풀이*
```java
class Solution {
    public int[] solution(int[] num_list) {
        int[] answer = new int[2];

        for(int i = 0; i < num_list.length; i++)
            answer[num_list[i] % 2]++;

        return answer;
    }
}
```

# 잘라서 배열로 저장하기

## 문제

문제 설명

>문자열 my_str과 n이 매개변수로 주어질 때, my_str을 길이 n씩 잘라서 저장한 배열을 return하도록 solution 함수를 완성해주세요.

제한사항

>1 ≤ my_str의 길이 ≤ 100
>
>1 ≤ n ≤ my_str의 길이
>
>my_str은 알파벳 소문자, 대문자, 숫자로 이루어져 있습니다.

## 내 답안

방법
1. my_str을 char[]로 분할(toCharArray())
2. Arrays.copyOfRange로 지정 인덱스로 분할
3. 분할한 char[]을 String으로 변환해 String[] answer에 대입

```java
import java.util.*;
class Solution {
    public String[] solution(String my_str, int n) {
        char[] c = my_str.toCharArray();
        String[] answer = new String[(c.length+(n-1))/n];
        for(int i=0;i<answer.length;i++){
            answer[i] = String.valueOf(Arrays.copyOfRange(c, i*n, (i+1)*n));
        }
        return answer;
    }
}
```

### 문제점

my_str의 길이가 n으로 나누어떨어지지 않는 경우 맨 뒤의 copyOfRange 결과가 남는다.

> 입력값 〉	"abc1Addfggg4556b", 6
>
> 기댓값 〉	["abc1Ad", "dfggg4", "556b"]
>
> 실행 결과 〉	실행한 결괏값 ["abc1Ad","dfggg4","556b\u0000\u0000"]이 기댓값 ["abc1Ad","dfggg4","556b"]과 다릅니다.

즉, 값이 없는 칸에 뒤에 \u0000(null문자)이 붙는 것.

### 해결책

```java
answer[i] = String.valueOf(Arrays.copyOfRange(c, i*n, (i+1)*n)).trim();
```

위와 같이 trim()으로 공백성 문자 제거.

### 분석

공백 판정 기준은 \u0020 이하. trim에 의해 제거됨.

## 개선안(AI)

char[]로 변환하는 것 자체가 불필요.

효율성 : String.substring(start, end) 메서드를 이용해 즉시 인덱스를 자를 수 있다.

문제 해결 : Math.min(num1, num2) 메서드를 이용해 끝 인덱스를 제한한다.

### 수정 결과
```java
import java.util.*;
class Solution {
    public String[] solution(String my_str, int n) {
        String[] answer = new String[(my_str.length()+(n-1))/n];
        for(int i=0;i<answer.length;i++){
            answer[i] = my_str.substring(i*n, Math.min((i+1)*n, my_str.length()));
        }
        return answer;
    }
}
```

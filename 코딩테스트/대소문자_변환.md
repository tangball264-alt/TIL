# 대소문자 변환

## 문제

>문제 설명
>
>문자열 my_string이 매개변수로 주어질 때, 대문자는 소문자로 소문자는 대문자로 변환한 문자열을 return하도록 solution 함수를 완성해주세요.
>
>제한사항
>
> - 1 ≤ my_string의 길이 ≤ 1,000
>
> - my_string은 영어 대문자와 소문자로만 구성되어 있습니다.

## 사용한 핵심 메서드/요소

1. Character.isUpperCase() / Character.isLowerCase()
- 입력받은 char인자가 대문자/소문자면 True 반환.

2. Character.toUpperCase() / Character.toLowerCase()
- 사실 이 문제에서는 불필요함. ascii코드 32를 더하거나 빼는 편이 오버헤드가 적음.

3. sb.setCharAt(int index, char ch)
- 스트링빌더의 .insert(index, ch)와 .deleteCharAt(index)를 합하여 대체하는 메서드
- 인덱스의 한 글자를 지정 char로 교체한다.


**to_____Case()는 문자열에도 사용 가능하다. char에 쓸 때는 Character.to_____Case(문자) 형태지만 String에 쓸 때는 문자열.to_____Case() 형태.**

물론 is_____Case()는 문자열에는 불가.

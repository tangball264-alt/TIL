# 피자 나눠 먹기(1)


## 문제
머쓱이네 피자가게는 피자를 일곱 조각으로 잘라 줍니다. 피자를 나눠먹을 사람의 수 n이 주어질 때, 모든 사람이 피자를 한 조각 이상 먹기 위해 필요한 피자의 수를 return 하는 solution 함수를 완성해보세요.

## 해석
사람이 7의 배수일 때 : n/7(피자 조각 수) 개 필요
사람이 7의 배수가 아닐 때 : n/7(피자 조각 수) + 1 개 필요

## 구현 방법

1. if문이나 ()?T:F 방식으로 7의 배수일 때, 아닐 때 구분
2. java.util.* 라이브러리의 Math.ceil 메서드 이용(단, ceil 함수는 double을 받아 double을 반환)
3. **정수만으로 올림 나눗셈 시의 일반화된 식** {n+(나눌 수-1)}/(나눌 수) 로 표현할수도.

### 예시(3)

>문제 설명
>
>머쓱이네 피자가게는 피자를 두 조각에서 열 조각까지 원하는 조각 수로 잘라줍니다. 피자 조각 수 slice와 피자를 먹는 사람의 수 n이 매개변수로 주어질 때, n명의 사람이 최소 한 조각 이상 피자를 먹으려면 최소 몇 판의 피자를 시켜야 하는지를 return 하도록 solution 함수를 완성해보세요.

```java
class Solution {
    public int solution(int slice, int n) {
        int answer = (n+slice-1)/slice;
        return answer;
    }
}
```

# 외계어 사전

## 문제

>문제 설명
>
>PROGRAMMERS-962 행성에 불시착한 우주비행사 머쓱이는 외계행성의 언어를 공부하려고 합니다. 알파벳이 담긴 배열 spell과 외계어 사전 dic이 매개변수로 주어집니다. spell에 담긴 알파벳을 한번씩만 모두 사용한 단어가 dic에 존재한다면 1, 존재하지 않는다면 2를 return하도록 solution 함수를 완성해주세요.
>
>
>제한사항
>
> - spell과 dic의 원소는 알파벳 소문자로만 이루어져있습니다.
> - 2 ≤ spell의 크기 ≤ 10
> - spell의 원소의 길이는 1입니다.
> - 1 ≤ dic의 크기 ≤ 10
> - 1 ≤ dic의 원소의 길이 ≤ 10
> - spell의 원소를 모두 사용해 단어를 만들어야 합니다.
> - spell의 원소를 모두 사용해 만들 수 있는 단어는 dic에 두 개 이상 존재하지 않습니다.
dic과 spell 모두 중복된 원소를 갖지 않습니다.


## 내 답안

```java
class Solution {
    public int solution(String[] spell, String[] dic) {
        boolean t = true;
        for(int i=0;i<dic.length;i++){
            if(dic[i].length()==spell.length){
                t = true;
                for(int j=0;j<spell.length;j++){
                    if(!dic[i].contains(spell[j])){
                        t = false;
                        break;
                    }
                }
                if(t){
                    return 1;
                }
            }
        }
        return 2;
    }
}
```

### 해석 및 평가

이중for문으로 dic의 문자열이 spell의 알파벳을 모두 포함하는지 확인한다.
- 문자열 길이가 알파벳 개수와 동일한지 검증하는 if문으로 연산횟수 줄이기
- boolean t를 이용해 내부 for문을 도중에 멈춰 반복 횟수를 줄이기
- 하나라도 '적절한 단어'가 나온다면 즉시 return하고 연산을 중지.

이중for문은 어쩔 수 없이 반복횟수가 늘어난다. 여러 방식으로 최대한 줄였지만 결국 2가 나오는 경우는 한계에 거까운 반복 횟수를 수행한다.

## 개선안

애너그램 분석 문제와 같은 방법으로, 문자배열을 정렬하여 검사한다.

1. spell을 문자 배열로 바꾸고(String.join("", spell)으로 문자열로 바꾼 후 toCharArray()) 정렬한다(Arrays.sort(arr))
2. dic의 각 문자열을 문자 배열로 치환한 후(toCharArray()) 정렬(Arrays.sort(arr))
3. 그 후 둘을 Arrays.equals(arr1, arr2)로 비교한다.

동일한 문자가 한 번씩 포함되었으니, 배열을 정렬하면 반드시 동일한 배열이 된다.

이렇게 하면 dic 길이만큼의 반복 1회로 해결된다.

메모리 소모가 적은 char[] 배열만 사용.
배열 생성에 따른 저장공간 소모가 조금 있긴 함.

Set사용 방법도 있지만 Arrays가 생성 및 비교에 소모되는 자원이 적다.

```java
import java.util.*;
class Solution {
    public int solution(String[] spell, String[] dic) {
        char[] spellChars = String.join("",spell).toCharArray();
        Arrays.sort(spellChars);
        for(String word : dic){
            if(word.length()==spellChars.length){
                char[] wordChars = word.toCharArray();
                Arrays.sort(wordChars);
                if(Arrays.equals(wordChars, spellChars)){
                    return 1;
                }
            }
            
            
        }
        return 2;
    }
}
```

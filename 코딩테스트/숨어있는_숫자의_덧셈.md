# 숨어있는 숫자의 덧셈

## 문제

## 내 답안
```java
class Solution {
    public int solution(String my_string) {
        String[] str = my_string.split("[^0-9]+");
        int answer = 0;
        for(String s : str){
            if(!s.isEmpty()){
                answer += Integer.parseInt(s);
            };
        }
        return answer;
    }
}
```

### 해석

1. split으로 숫자가 아닌 것들(정규식)을 기준으로 잘라낸다.
- 결과적으로 맨 앞의 내용없는 배열(숫자로 시작할 경우 없음)과 일부 숫자 배열이 생긴다.
- 이어진 숫자가 묶음으로 저장된다는 게 장점.
2. 반복문으로 각 숫자를 answer에 더한다.
- 빈 값을 더하려 하면 오류가 발생. isEmpty로 구분한다.

### 개선안

split으로 나누면 빈 배열 발생.

Pattern/Matcher로 숫자 덩어리만 직접 찾으면 개선 가능.(AI)

실제 pattern/matcher의 사용법 등에 대해서는 별도로 공부와 분석 필요.

## 다른 사람 코드


1. split대신 replaceAll을 이용하여 글자를 공백으로 바꾸기.
2. 그 다음 StringTokenizer 이용해 공백을 구분자로 토큰화(연속된 구분자를 자동으로 하나로 취급.)
- 빈 토큰 없음. 따라서 isEmpty() 체크 생략되어 간결함.
- 정규식 횟수 동일.

혹은 stream을 이용해 사실상 나의 코드와 동일한 진행을 할 수 있음.

이 경우 효율성은 비슷하나 코드가 간결함.
